优化

藤青晚安 · 秋风纷落 皮肤细节优化
修复跳跃情况下人物表情问题

服务器与静态资源

  • 检查皮肤资源接口响应时间，确认 TTFB 是否正常。
  • 查看服务器 CPU、内存、磁盘 IO 是否在高负载下触发卡顿。
  • 检查带宽是否被皮肤包下载打满。
  • 开启 Nginx/Apache 静态资源缓存。
  • 对皮肤图片、JSON、配置开启 Gzip/Brotli 压缩。
  • 启用 HTTP/2，减少并发请求排队。
  • 将皮肤资源接入 CDN，降低源站压力。
  • 配置 CDN 缓存策略，避免每次回源。
  • 开启 Range 回源，优化大皮肤包下载。
  • 检查 CDN 缓存命中率，排除频繁刷新缓存。
  • 将皮肤资源域名与业务接口域名分离，做动静分离。
  • 检查 DNS 解析耗时，必要时更换 DNS。
  • 检查服务器连接数是否接近上限。
  • 开启 tcp_tw_reuse，减少 TIME_WAIT 堆积。
  • 调整文件描述符限制，避免高并发下请求失败。
  • 检查 Nginx worker 数是否与 CPU 核数匹配。
  • 限制单 IP 下载频率，防止异常爬虫拖垮带宽。
  • 为皮肤资源设置合理的 Cache-Control。
  • 为皮肤资源设置 ETag/Last-Modified，支持协商缓存。
  • 检查 HTTPS 会话复用，减少重复握手。
  • 检查源站与 CDN 之间回源延迟。
  • 对跨运营商访问启用多线/CDN 就近接入。
  • 检查服务器磁盘是否接近满盘。
  • 将高频读取的皮肤资源放到 SSD。
  • 使用 iostat 排查磁盘 IO 瓶颈。
  • 将临时解压目录挂载到 tmpfs。
  • 合并小尺寸皮肤贴图，减少请求数量。
  • 拆分超大皮肤包，避免单次下载阻塞。
  • 为皮肤资源建立版本化路径，方便缓存更新。
  • 检查资源 URL 是否带随机参数导致缓存失效。

皮肤资源与客户端加载

  • 检查皮肤贴图是否过大，优先使用合适分辨率。
  • 使用 WebP/ASTC/ETC2 等更优格式。
  • 为皮肤图集做纹理压缩，降低显存占用。
  • 避免一次性加载全部皮肤，改为按需加载。
  • 在商城、背包、预览页提前预加载常用皮肤。
  • 使用 Addressables/AssetBundle 做资源分片。
  • 避免主线程同步加载皮肤资源。
  • 为皮肤加载增加进度条或占位图。
  • 首屏不强制加载非必需皮肤资源。
  • 检查皮肤资源是否存在重复贴图。
  • 合并同角色皮肤到独立图集，减少内存浪费。
  • 为未使用皮肤设置延迟卸载。
  • 切换皮肤时复用已有材质，避免频繁重建。
  • 检查 Shader 变体是否过多导致编译卡顿。
  • 降低动态皮肤动画帧率，减少性能消耗。
  • 对低配设备使用简化版皮肤。
  • 检查皮肤资源是否触发频繁 GC。
  • 为皮肤资源建立本地缓存，避免重复下载。
  • 断网或弱网时优先展示已缓存皮肤。
  • 下载失败时提供重试和降级方案。
  • 检查资源包签名与完整性，避免加载异常。
  • 避免在战斗/高负载场景触发大规模资源加载。
  • 皮肤预览页使用低分辨率占位图。
  • 检查 UI 皮肤是否造成过多 Overdraw。
  • 为换装界面增加对象池，减少频繁创建销毁。
  • 检查皮肤切换是否阻塞渲染线程。
  • 避免在 Update 中频繁请求皮肤数据。
  • 检查皮肤资源是否存在循环依赖。
  • 为不同机型设置皮肤加载上限。
  • 记录皮肤加载耗时，用于线上监控。

后端接口与缓存

  • 检查皮肤列表接口是否存在慢查询。
  • 为皮肤表增加索引，避免全表扫描。
  • 使用 Redis 缓存热门皮肤信息。
  • 避免每次打开商城都查数据库。
  • 检查皮肤配置接口是否返回过多无用字段。
  • 对皮肤数据做分页加载。
  • 检查接口是否频繁重试导致压力放大。
  • 为皮肤下载链接设置短期签名，避免泄露。
  • 检查皮肤资源 URL 是否集中命中同一节点。
  • 对高并发皮肤查询做限流。
  • 对非核心皮肤逻辑异步化处理。
  • 检查线程池是否被打满。
  • 排查接口是否存在 N+1 查询。
  • 检查皮肤权限校验是否过于昂贵。
  • 对已拥有皮肤做本地/服务端缓存。
  • 避免在热点接口中做复杂计算。
  • 检查日志级别，关闭不必要的 DEBUG 日志。
  • 对皮肤下载日志做异步写入。
  • 检查是否有定时任务与皮肤加载高峰冲突。
  • 对皮肤资源元数据做本地缓存。

网络、同步与安全

  • 检查皮肤资源服务器延迟与丢包。
  • 对弱网用户降低皮肤包并发下载数。
  • 检查是否因跨域导致资源加载失败。
  • 检查 CORS 配置是否正确。
  • 检查 CDN 节点是否覆盖主要用户区域。
  • 对动态皮肤请求使用独立域名。
  • 检查 HTTPS 证书是否导致握手异常。
  • 检查防火墙是否拦截皮肤资源请求。
  • 检查安全软件是否误判资源下载。
  • 排查恶意爬虫大量拉取皮肤资源。
  • 对异常下载行为做频率限制。
  • 检查服务器是否被挖矿/病毒占用资源。
  • 检查端口和权限是否最小化。
  • 检查日志中是否有异常 IP 访问。
  • 对皮肤资源访问做基础鉴权。
  • 检查资源链接是否被外部盗链。
  • 为盗链请求返回 403 或跳转。
  • 监控皮肤接口错误率。
  • 建立皮肤加载卡顿告警。
  • 用压测复现高并发皮肤加载场景，验证优化效果。
